# CareerKraft

CareerKraft is an enterprise-style resume and cover letter builder built with Angular, NgRx, Node.js, PostgreSQL, and Prisma.

## Goal

Build, edit, preview, and export professional resumes and cover letters.

## Tech Stack

- Angular
- NgRx
- Node.js / NestJS
- PostgreSQL
- Prisma
- GitHub Actions
- Docker

## Planned Features

- Resume editor
- Cover letter editor
- Live preview
- PDF export
- Saved documents
- Responsive UI
- Accessibility-focused UX
