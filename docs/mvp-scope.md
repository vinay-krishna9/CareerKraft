# MVP Scope

## Goal

CareerKraft helps users create, edit, preview, save, and export resumes and cover letters.

## MVP Features

- Create and edit a resume
- Add personal information
- Add work experience
- Add education
- Add skills
- View live resume preview
- Export resume as PDF
- Create and edit a cover letter
- Save documents to the database

## Out of Scope for MVP

- AI resume generation
- ATS scoring
- Resume import
- Multiple languages
- Payments
- Public sharing links

## First Milestone

Build the frontend foundation with Angular, routing, layout shell, and a basic resume editor page.
